# leitvia/update-block

Generated from Leitvia Studio 1.3.60. Do not edit. Group: Build. How to call abilities, hashes, autonomy and rejections: [agent handbook](../README.md).

**Update block.** Changes one block found by its ID or path ID: attributes from the block catalog and the level of a heading, the text of a paragraph, heading, list item or button, the citation of a quote, the summary of a details block, the link of a button or of the one link in a text (link_text names the linked part, also for a text that gets its first link), words in a text with replace_text (find and with), which keeps all links and inline formatting, also where text is refused for several links, the cells of a core/table or leitvia/comparison-table with table (head, rows, foot), or the image of an image or cover block with alt text. video sets the video of a core/video from the media library by its ID, with poster, controls and preload none, also on the empty video of a pattern. add_link sets a new link on a passage of a text, emphasis sets a passage in italics (with font in another font role), strike strikes one through, mark sets one in another font role, text color or size, caption the caption of an image, video, audio, gallery, table or embed, anchor the HTML anchor of a block with the support anchor (unique on the page), columns the column count of a grid (group or post template with the layout grid) or of a gallery. A heading or paragraph takes fontSize with a font size of the tokens, fontFamily with a font role (body, heading, mono, ui) and textAlign (left, center, right), a group with a light ground takes backgroundColor surface, surface-alt or an extra surface of the token set (surface-extra-\<name>), each as attribute. A core/navigation takes overlayMenu (never, mobile, always), overlayBackgroundColor and overlayTextColor (color roles or extra surfaces; not with the template part navigation-overlay, whose outer group takes backgroundColor), hasIcon and icon (handle, menu), and text, the word on its menu button; a navigation link or submenu takes text and url. A core/column takes width in percent, a core/button fontSize. Text takes line breaks as a new line or \<br>. label changes the name for screen readers (aria-label) of a slider, announcement bar or accessibility bar. A timeline entry takes date, dateLabel and heading as attributes. Attributes that a static block keeps in its markup, such as prefix, value, suffix and label of a counter, change like any other. query of a core/query merges into its settings. tracks of a core/video replaces its text tracks: each names a WebVTT file from leitvia/add-media by id, with kind, srclang and label. A spotlight point moves with attributes x and y in percent. The effect on scroll (leitviaAnimation, leitviaMotion) changes on every block that has it, core blocks and saved markup included, since only the block comment changes. Static markup is rebuilt with the HTML API; changes it cannot rebuild safely are rejected with leitvia_static_markup. Read the post with leitvia/get-page-outline first and send its hash as base_hash; get-block shows the current attributes. For several text changes in one post use leitvia/update-content.

MCP tool `leitvia-update-block`, REST POST. Annotations: readonly false, destructive true, idempotent false.

| Input | Type | Required | Description |
|---|---|---|---|
| `block` | string, min length `1`, max length `200` | yes | Block ID or path ID from the outline. |
| `text` | string, max length `5000` |  | Plain text of a paragraph, heading, list item or button, the citation of a quote, the summary of a details block, the text of a navigation link or submenu, or the word on the menu button of a core/navigation (instead of Menu, up to 30 characters). A line break (a new line or \<br>) becomes a br in a paragraph, heading, list item or button; other markup stays text. |
| `link_text` | string, min length `1`, max length `500` |  | Part of text that stays linked when the text holds a link, such as the mail address in a contact line; with url it links that part of a text without a link. Without it the link stays around its old text, and a text without that is refused unless the link only points to #. |
| `url` | string, max length `2000` |  | Link of a button, of a navigation link or submenu, or of the one link in a paragraph, heading or list item (mailto: and tel: work too). "" removes the saved link of a button whose link a binding fills; the binding stays. |
| `add_link` | object { text\*, url\* } |  | New link around a passage of a paragraph, heading, list item, citation or summary, as text with the exact words and url. Other links and inline formatting stay; the first place outside a link counts. |
| `emphasis` | object { text\*, font }, min length `1`, max length `500` |  | The exact words of a passage of a paragraph, heading, list item, button, citation or summary to set in italics (em), such as one word of a claim or a button label; the first place outside a link and outside italics counts, else the first inside a link (a linked title in italics), within one run of text. Links and other formatting stay. text in the same edit comes first, so a new text can take its italic word at once. As an object, text with font sets the italic words in another font role, such as the italic of the ui font in a serif heading: {"text": "your", "font": "ui"}. |
| `strike` | string, min length `1`, max length `500` |  | The exact words of a passage to strike through (s), such as a phrase the text takes back; found like emphasis, and both on the same words give italics struck through. |
| `mark` | object { text\*, font, color, size } |  | A passage in another font role, text color or size (mark, as the text color format of the editor saves it), found like emphasis: text with font (body, heading, mono, ui), color (ink, ink-muted, accent) and size (a font size of leitvia/get-tokens), at least one of them. Such as a small number in mono and accent before the words of a heading on the same baseline, {"text": "01", "font": "mono", "color": "accent", "size": "heading-l"}, or quotation marks in accent. |
| `replace_text` | object { find\*, with\* } |  | Replaces words in the text of a paragraph, heading, list item, button, citation or summary and keeps every link with its target and inline formatting such as strong and em, also in a text with several links, where text is refused. find must stand once in the text and within one run of text: words across a link or formatting, such as a price in strong with the words around it, are refused, so replace the part inside on its own. Not together with text. |
| `caption` | string, max length `1000` |  | Caption of an image, video, audio, gallery, table or embed as plain text; empty removes it. |
| `anchor` | string or null, max length `100` |  | HTML anchor (id) of a block with the support anchor, unique on the page, such as contact-form for links to #contact-form; empty or null removes it. |
| `bind` | object |  | Block bindings per attribute, written to metadata.bindings: {"content": {"source": …, "args": {…}}} shows a value of the source in place of the saved text, such as a field, a site setting or, with an add-on, a price; null removes the binding of that attribute. Sources and bindable attributes come from leitvia/get-content-model (bindings). The text of the same edit stays as the saved fallback. |
| `table` | object { head, rows\*, foot, row_headers } |  | All cells of a core/table or leitvia/comparison-table as plain text: head (the column headers; a core/table without it has no header row, a comparison table keeps its own), rows (each as long as head, or as the first row) and for core/table foot (a highlighted closing row, such as a total). The table is rebuilt accessibly: column headers with scope col, the first cell of each row as row header with scope row (row_headers false for none). The caption goes in caption of the same edit; in a section of compose-page, insert-section or replace-pattern a table without caption drops the sample caption of the pattern. On small screens core tables scroll inside a focusable region, the comparison table turns into cards. |
| `columns` | integer, min `1`, max `6` |  | Column count of a grid or a gallery: a group or post template with the layout grid, such as the cards of a teaser pattern, or a gallery block. Four cards take 2: with 4 a narrower window still wraps to 3 + 1. |
| `image` | object { id\*, alt, decorative } |  |  |
| `video` | object { id\*, poster } |  | Video of a core/video from the media library: sets src, poster, controls and preload none, also on a video block that is still empty. caption and attributes with tracks or align go in the same edit. Text tracks the block has stay; send tracks when the new video has other captions. |
| `attributes` | object |  | Attributes from leitvia/list-blocks; for a core/heading its level, 1 to 6; for a core/query query with perPage, pages, offset, postType, order, orderBy, sticky and inherit (perPage counts with inherit false); for a core/video tracks, each with id, kind, srclang and label (its file, poster, controls and preload come from the field video); for a leitvia/timeline-item date (YYYY, YYYY-MM or YYYY-MM-DD, empty for a free label), dateLabel and heading; leitviaAnimation and leitviaMotion on every block that lists them, also next to other attributes (null removes either); className (is-style-\<name>, null removes the style and keeps other classes; up to three styles that combine space separated, such as is-style-sticky-header-desktop is-style-overlay-header) on every core block with registered block styles; textColor (ink, ink-muted or accent), fontSize, fontFamily (a font role of the theme: body, heading, mono or ui) and textAlign (left, center or right) on a core/heading or core/paragraph; on a core/group with a light ground backgroundColor surface, surface-alt or an extra surface (surface-extra-\<name>); on a core/navigation overlayMenu (never, mobile or always: always shows the menu button on every width), overlayBackgroundColor and overlayTextColor (surface, surface-alt, ink, accent, on-accent or surface-extra-\<name>), hasIcon (false shows the word Menu, or the word of text) and icon (handle or menu), but no overlay colors when the menu opens the template part navigation-overlay (its outer group takes backgroundColor); fontSize on a core/quote, so the quotes of a row match (null for the size of the theme), and on a core/button, such as a larger shape button; width on a core/column in percent, such as 66.66% (null shares the free space), set for all columns of the row together; textColor with a color role and fontSize on a block of Studio or an add-on whose supports in leitvia/list-blocks name color.text or typography.fontSize, such as leitvia/icon and leitvia/icon-list (null removes either); on a core/cover minHeight in vh, 30 to 100, and focalPoint, x and y from 0 to 1, the part of the photo that stays in view where the cover crops it, as on phones (null for the middle); align on every block whose supports.align in leitvia/list-blocks names the value (null removes it); on core/image also width, height, aspectRatio, scale, sizeSlug, linkDestination, href, lightbox (null removes one). null puts any attribute back to its default, such as {"label": null}: one of the block comment is left out, one kept in the markup takes the default of its block type; null for an attribute the block does not have changes nothing. |
| `post` | integer, min `1` | yes | Post ID from leitvia/list-content. |
| `base_hash` | string | yes | Hash of the target as last read; empty for a new object. |
| `package` | string, max length `64` |  | Key of the task: a write with a key always goes into the change package of that key, even where the autonomy would allow it live, and operations with the same key share that package. |

Output: the write result. Its fields: [Write results](../README.md#write-results).
