# leitvia/set-page-structure

Generated from Leitvia Studio 1.3.62. Do not edit. Group: Maintain. How to call abilities, hashes, autonomy and rejections: [agent handbook](../README.md).

**Set page structure.** Sets what a page is within the site, for breadcrumbs, structured data, llms.txt and the composition check. kind is the kind of the page as compose-page sets it, such as imprint or privacy for a legal text that came in with leitvia/import-post; a legal kind keeps the page at suggest. frame is the type of a page frame of the contract (hub for the overview of a topic, audience, service), so check-composition counts the sections that frame requires or recommends; compose-page sets it too. hub is the ID of the overview page the page belongs to: pages keep flat addresses, and the breadcrumbs (block and BreadcrumbList) show Home, the hub of the hub, the hub and the page; the hub wins over a parent page, and a page without a hub keeps the trail of its parents. breadcrumbs false hides the breadcrumbs of the template on this page alone, true shows them again. service is what the page offers: name, description, price as a number, currency (EUR), vat_included (false for a net price) and unit (per month); with a price Leitvia Studio prints a Service with an Offer and a UnitPriceSpecification, without an SEO plugin. type software makes it a SoftwareApplication (a plugin, an app) with application_category, operating_system and download_url, with or without a price (0 for free software). The kinds about and contact print an AboutPage and a ContactPage. max_price makes the price a range (from price up to max_price, an AggregateOffer); offers lists the packages of the service, each with name, price and optional max_price (its price is a range), description and unit (up to 10), printed as one Offer per package in an AggregateOffer with the lowest price and the highest of all prices and ranges, and price may then stay empty. offerings links the page to offerings an add-on keeps (line: slug of a line, skus: article numbers); such an add-on shows them on the page and takes the service of the page from them. Use only what the page itself says. An empty string, 0 or null clears a field. Read the page with leitvia/get-page-outline first and send its hash as base_hash; autonomy and change packages work as for leitvia/update-content.

MCP tool `leitvia-set-page-structure`, REST POST. Annotations: readonly false, destructive false, idempotent true.

| Input | Type | Required | Description |
|---|---|---|---|
| `post` | integer, min `1` | yes | ID of a page from leitvia/list-content. |
| `news` | object { categories, tags } |  | Topic of the news of a page: categories and tags by ID or slug, as posts carry them (terms in leitvia/list-content). The pattern Related news on the page lists the latest posts with any of them, the latest posts when none has one. null clears it. |
| `frame` | string, max length `40` |  | Type of a page frame of the contract, for example hub; empty clears it. |
| `kind` | one of ``, `imprint`, `privacy`, `terms`, `withdrawal`, `accessibility`, `editorial`, `contact`, `authors`, `about` |  | Kind of the page, such as imprint or privacy for a legal text that was imported or written before; empty clears it. A legal kind (imprint, privacy, terms, withdrawal, accessibility) keeps the page at suggest: the change waits in a package for a person. |
| `hub` | integer, min `0` |  | ID of the published overview page above this page; 0 clears it. For a post or an entry with a page of its own (such as documentation): the page of the service it is about, shown as a card beside or below it. |
| `breadcrumbs` | boolean |  | false hides the breadcrumbs of the template on this page, and their BreadcrumbList with them, such as on a page whose title section stands right below the header as in the design; true shows them again (the default). |
| `icon` | string, max length `40` |  | Lead symbol of a hub: the name of an icon from leitvia/list-blocks (Lucide), shown by icon blocks bound to leitvia/page-symbol, such as the panel of the pattern hero-symbol; empty clears it. |
| `service` | object { name\*, description, price, currency, vat_included, unit, max_price, type, application_category, operating_system, download_url, offers } |  |  |
| `offerings` | object { line, skus } |  | Offerings an add-on keeps that this page presents: line is the slug of a line of offerings, skus lists article numbers of single offerings (they win over line). Leitvia Studio stores the link; an add-on that keeps offerings shows them on the page and gives the page its service from them. null clears it. |
| `base_hash` | string | yes | Hash of the target as last read; empty for a new object. |
| `package` | string, max length `64` |  | Key of the task: a write with a key always goes into the change package of that key, even where the autonomy would allow it live, and operations with the same key share that package. |

Output: the write result. Its fields: [Write results](../README.md#write-results).
