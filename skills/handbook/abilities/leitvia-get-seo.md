# leitvia/get-seo

Generated from Leitvia Studio 1.3.62. Do not edit. Group: Read. How to call abilities, hashes, autonomy and rejections: [agent handbook](../README.md).

**Get SEO data.** Returns the SEO data of posts, pages and entries from the active SEO plugin. Supported are Yoast SEO, Rank Math, SEOPress and The SEO Framework. Per item: title, meta description, canonical, noindex, nofollow, Open Graph title, description and image, focus keyword and schema type. schema_type is the article type Leitvia Studio prints for a post (NewsArticle or BlogPosting), null where it prints none; structure holds the page frame, hub, service and offerings of a page (leitvia/set-page-structure). indexable says whether the site is open to search engines, news_sitemap is the address of the news sitemap of Leitvia Studio or null and news_sitemap_held_back why it is not served (site closed to search engines, setting off, another news sitemap plugin), an empty string while it is served; organization holds the details of leitvia/set-organization: type, name, url, description, logo (media ID, 0 for the logo of the header), address, phone, email, founding date, founder, people (profiles of persons), start year and holder of the copyright line, area served, opening hours, profiles and aggregate_rating. redirects lists the rows of leitvia/set-redirects, llms whether llms.txt was asked for (requested) and is served (enabled), held_back why a requested file is not served (site closed to search engines, SEO plugin), its address, summary, extra pages, the number of latest posts (news), the Disallow paths of robots.txt (disallow) and whether AI crawlers may crawl (leitvia/set-llms). An empty value means the plugin falls back to its template. defaults holds what WordPress itself would print and a description suggested from the excerpt; without an SEO plugin plugin names Leitvia Studio, with an unsupported one seo is null, and notice says why. hash is the base_hash of leitvia/update-seo. IDs that are no readable content come back under skipped.

MCP tool `leitvia-get-seo`, REST GET. Annotations: readonly true, destructive false, idempotent true.

| Input | Type | Required | Description |
|---|---|---|---|
| `posts` | array of integer, min `1`, min items `1`, max items `50` | yes | IDs of posts, pages or entries from leitvia/list-content. |

Output: `plugin` object { key, name, writable }; `notice` string; `items` array of object { post, type, status, title, url, hash, seo, defaults, schema_type, structure }; `skipped` array of integer; `indexable` boolean; `news_sitemap` string or null; `news_sitemap_held_back` string; `redirects` array of object; `llms` object; `organization` object { type, name, url, description, logo, street, postal_code, city, country, phone, email, contact_type, founding_date, founder, copyright_since, copyright_holder, area_served, opening_hours, same_as, people, aggregate_rating }.
